📖 Developer Getting Started Guide


1. Prerequisites

Ensure you have the following installed on your machine:

  • Azure CLI: Run `az login` to authenticate with your Azure Subscription.
  • Terraform CLI: Version 1.0 or higher. Check with `terraform version`.
  • Git: For version control and tracking changes.

2. Deployment Workflow

# Navigate to environment directory
cd parent_modules/dev

# Initialize Terraform modules & providers
terraform init

# Review execution plan
terraform plan -var-file="terraform.tfvars"

# Deploy Azure infrastructure
terraform apply -var-file="terraform.tfvars" -auto-approve

3. Module Architecture Best Practices

Har module child modules folder me localized logic maintain karta hai. Parent module `for_each` loop ke zariye parameters accept karta hai, jisse dynamic multi-resource creation bohot flexible ho jaati hai!
